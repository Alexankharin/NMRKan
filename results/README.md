# Results

`reference/` is the versioned evidence supplied with this project. Treat it as input when validating models or rebuilding reports. Fresh generated data, trained models and figures belong under `outputs/` at the repository root, which is ignored by Git.

`reproduced/2026-11-08/` contains the subsequent complete paper training runs, executed notebooks, and comparisons with the manuscript. These fresh results are distinct from the historical molecular reference artifacts.
